# Jennifer's Portfolio

A responsive portfolio website created for my Web Development class.

## Accessibility improvements

- Added descriptive alternative text to the Home page image so screen reader users can understand it.
- Removed an empty navigation link so every link has a purpose.
- Removed the temporary low contrast text from the Home page.
- Added labeled, required fields and clear validation messages to the About/Contact form.

## WAVE testing

I tested all three pages with WAVE after making my changes:

- Home (`index.html`): __0_ errors, _0__ contrast errors, __0_ alerts
- Projects (`projects.html`): _0__ errors, _0__ contrast errors, __0_ alerts
- About/Contact (`about.html`): _0__ errors, __0_ contrast errors, __0_ alerts

## Gestalt principles

- **Proximity:** I grouped related content into portfolio cards so visitors can tell which information belongs together.
- **Similarity:** I used consistent card styles, headings, and colors across the pages so the site feels connected and is easier to scan.
